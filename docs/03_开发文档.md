# 开发文档

## 关键版本

```python
PLUGIN_VERSION = "3.5.1-ida93-pyside6-zh"
CORE_VERSION = "3.5.1-ida93-pyside6-zh"
CONFIG_SCHEMA_VERSION = 10
```

## 新增动作

```python
ACTION_SHOW_PANEL = "ida_pseudocode_exporter:show_panel"
ACTION_EXPORT_NAMES = "ida_pseudocode_exporter:export_all_function_names"
```

动作通过 `ida_kernwin.register_action()` 注册，并挂载到 `Edit/Plugins/`。

## 新增核心函数

### collect_all_function_name_records

返回当前数据库全部函数名称记录。每条记录包含地址、长度、段、原始名、反混淆名、显示名和函数标志。

### export_all_function_names

写入 CSV、JSON、纯函数名 TXT 和摘要文件，并返回输出目录。

## 二次开发建议

- 增加字段时优先扩展 `collect_all_function_name_records()` 的 record 字典。
- 修改输出格式时优先调整 `export_all_function_names()`。
- 伪代码导出与函数名称导出应保持解耦，避免名称导出依赖 Hex-Rays。
