# 常见问题与排错

## 1. No module named PySide6

请确认使用的是 IDA 9.3 自带 Python 环境，并且没有用系统 Python 启动插件静态导入。插件不再支持 PyQt5。

## 2. 打开面板失败

查看 IDA Output 窗口中的 `通用函数伪代码导出器` 日志。常见原因包括插件目录不完整、`ida-plugin.json` 未与入口文件同目录、PySide6 环境被第三方插件污染。

## 3. 伪代码导出失败但函数名称导出正常

函数名称导出不依赖 Hex-Rays；伪代码导出依赖当前架构对应的 Hex-Rays 反编译器插件和许可证。请先在目标函数按 F5 验证反编译器是否可用。

## 4. 输出路径过长

插件会自动缩短类目录和文件名。必要时会自动切换到短路径存储目录，并在运行目录写入 redirect 说明文件。

## 5. 如何只拿函数名列表

直接使用 `导出全部函数名称`，然后读取：

```text
all_function_raw_names.txt
```

如果希望优先获得反混淆后的名称，读取：

```text
all_function_display_names.txt
```
