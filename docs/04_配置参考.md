# 配置参考

用户配置文件：

```text
<IDA 用户目录>/ida_pseudocode_exporter_v3_5_0_ida93_config.json
```

默认配置文件：

```text
ida_pseudocode_exporter_config.json
```

本版本不再读取 `v3_4_x` 旧版配置。

关键字段：

| 字段 | 默认值 | 说明 |
|---|---:|---|
| `config_schema_version` | `10` | 当前配置结构版本 |
| `plugin_version` | `3.5.0-ida93-pyside6-zh` | 插件版本 |
| `output_dir` | 空 | 输出根目录；为空时使用 IDB 同级默认目录 |
| `scope` | `all_internal` | 伪代码导出范围 |
| `group_files_by_batch` | `true` | 是否按批次目录分组 |
| `functions_per_batch_folder` | `1000` | 每个批次目录函数数 |
| `group_files_by_class` | `true` | 是否按类/命名空间目录分组 |
| `stable_mode` | `true` | 是否启用稳定模式 |
| `clear_all_cache_interval` | `10` | Hex-Rays 全局缓存清理间隔 |
| `python_gc_interval` | `10` | Python GC 间隔 |
