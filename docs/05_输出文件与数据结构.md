# 输出文件与数据结构

## 伪代码导出

运行目录：

```text
run_<时间戳>/
```

主要文件：

```text
functions/                         单函数伪代码文件
attempts/attempt_<时间戳>/          本次尝试报告
manifest_<session>.csv             全局导出清单
completed_<session>.jsonl          已处理函数状态
active_function_checkpoint.json    当前函数崩溃检查点
quarantined_functions.json         隔离函数列表
```

## 全部函数名称导出

目录：

```text
function_names_<数据库名>_<时间戳>/
```

文件：

```text
all_function_names.csv
all_function_names.json
all_function_raw_names.txt
all_function_display_names.txt
summary.txt
```

`all_function_names.csv` 字段：

```text
index,address,start_ea,end_ea,length,segment,raw_name,demangled_name,display_name,flags_hex,is_library,is_thunk,is_import_name
```
