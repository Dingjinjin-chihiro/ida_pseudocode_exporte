# 用户使用手册

## 运行环境

- IDA Pro 9.3
- IDAPython
- PySide6 / Qt6
- Hex-Rays Decompiler：仅批量导出伪代码时需要；导出全部函数名称不需要。

## 安装

将插件目录复制到 IDA 9.3 的 `plugins` 目录下，保持 `ida-plugin.json` 与两个 Python 源码文件在同一目录。

## 批量导出伪代码

1. 打开 IDB/I64。
2. 等待必要的自动分析完成。
3. 执行 `Edit → Plugins → 通用函数伪代码导出器：打开导出面板`。
4. 选择导出范围、筛选规则、输出目录和稳定性参数。
5. 点击 `仅预演` 查看目标函数数量，确认后点击 `开始导出`。

## 单独导出全部函数名称

点击面板底部的 `导出全部函数名称`，或执行菜单：

```text
Edit → Plugins → 通用函数伪代码导出器：导出全部函数名称
```

此功能只枚举 IDA 当前数据库中的函数，不反编译函数体，速度更快，也不会因为 Hex-Rays 失败而停止。
