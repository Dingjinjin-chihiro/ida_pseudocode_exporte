# 实现原理文档

## 架构

插件分为两层：

- `ida_pseudocode_exporter.py`：IDA 插件入口、PySide6 界面、菜单动作、用户交互。
- `ida_pseudocode_export_core.py`：函数筛选、路径优化、伪代码导出、报告写入、全部函数名称导出。

## IDA 9.3 / PySide6 界面

插件直接使用：

```python
from PySide6 import QtCore, QtWidgets
```

`PluginForm` 创建时使用：

```python
parent = ida_kernwin.PluginForm.TWidgetToQtPythonWidget(form)
```

不再保留 PyQt5 导入和旧版兼容层。

## 伪代码导出流程

1. 读取配置。
2. 检查或延迟加载 Hex-Rays。
3. 枚举函数并应用筛选规则。
4. 写入选择报告。
5. 逐函数调用 `ida_hexrays.decompile()`。
6. 写入 `.c` 伪代码文件、manifest、失败日志和摘要。

## 全部函数名称导出流程

核心入口：

```python
export_all_function_names(output_root, logger)
```

内部调用：

```python
collect_all_function_name_records(logger)
```

该流程只使用 `idautils.Functions()`、`ida_funcs.get_func()`、`ida_funcs.get_func_name()`、`idc.demangle_name()` 和段信息 API，不调用 Hex-Rays 反编译接口。
