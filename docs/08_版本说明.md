# 版本说明

## 3.5.1-ida93-pyside6-zh

当前版本只面向 IDA 9.3。

### 主要变化

- PyQt5 → PySide6。
- Qt5 枚举 → Qt6 枚举。
- `FormToPyQtWidget()` → `FormToPySideWidget()`。
- 新增全部函数名称导出，不依赖 Hex-Rays。
- 新增 IDA 菜单动作，允许不打开主面板直接导出函数名称。
- 用户配置文件切换到 `ida_pseudocode_exporter_v3_5_0_ida93_config.json`。

### 不再支持

- IDA 9.0。
- PyQt5。
- 旧版用户配置自动迁移读取。
